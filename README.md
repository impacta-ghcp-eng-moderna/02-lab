# Lab 02 — Engenharia de Software Moderna

Este lab dá continuidade à aplicação de catálogo de treinamentos concluída no Lab 01.
A branch atual representa o ponto de partida da atividade, preservando a base necessária
para a evolução proposta neste módulo.

O Lab 02 foi dimensionado para aproximadamente **60 minutos**. A dinâmica final será
guiada por uma issue, que apresentará as orientações e os critérios da atividade.
